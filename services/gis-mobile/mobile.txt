5. CAPACITOR HTTP NATIF
--------------------------------------------------------------------------------
- Fichier : capacitor.config.ts
- Ajouté : CapacitorHttp: { enabled: true }

  POURQUOI : Sans cette option, les requêtes HTTP Angular passent par le WebView
  (XMLHttpRequest), qui est soumis aux restrictions Android (cleartext HTTP bloqué)
  et au CORS. Avec CapacitorHttp activé, toutes les requêtes sont routées via
  la couche native Android, ce qui bypasse CORS et les restrictions cleartext.

8. SIGNATURE APK (Release)
--------------------------------------------------------------------------------
- Keystore : calypso-release.keystore
  - Algorithme : RSA 2048-bit
  - Alias : calypso
  - Mot de passe : Calypso2026!
  - Validité : 10 000 jours (~27 ans)
  - DN : CN=Calypso, OU=Mobile, O=Belive, L=Tunis, ST=Tunis, C=TN

- Fichier : android/app/build.gradle
  - signingConfigs.release configuré avec le keystore
  - buildTypes.release utilise signingConfig signingConfigs.release

- IMPORTANT : Ne jamais perdre le keystore ! Toute mise à jour future
  de l'APK DOIT être signée avec le même keystore, sinon les utilisateurs
  devront désinstaller et réinstaller l'application.


9. BUILD APK
--------------------------------------------------------------------------------
Prérequis installés sur la machine de développement :
- JDK 21 (Microsoft OpenJDK 21.0.10)
- Android SDK (command-line tools + platform 35 + build-tools 35.0.0)

Commandes pour rebuild l'APK :
  1. npm run build -- --configuration=production
  2. npx cap sync android
  3. cd android && .\gradlew.bat assembleRelease

L'APK signée se trouve dans :
  android/app/build/outputs/apk/release/app-release.apk
