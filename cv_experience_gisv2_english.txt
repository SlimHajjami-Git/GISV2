SENIOR FULL-STACK DEVELOPER — GPS Fleet Management System (GISV2)
==================================================================

Stack: Rust, .NET 8, Angular 17, PostgreSQL/PostGIS, Redis, RabbitMQ, Docker
Role : Lead Developer / Technical Architect


PROJECT OVERVIEW
----------------
Design and development of a multi-tenant SaaS platform for real-time
vehicle fleet management. The system handles live GPS tracking,
geofencing, activity reports, preventive maintenance, cost management
and accident claims, serving multiple transportation companies.


RESPONSIBILITIES & ACHIEVEMENTS
--------------------------------

>> Architecture & Technical Leadership

  - Defined the overall distributed system architecture:
    high-performance GPS ingestion service (Rust) + business API (.NET 8)
    + real-time frontend (Angular 17)
  - Implemented Clean Architecture with CQRS pattern (MediatR)
    for strict separation of concerns
  - Designed the multi-tenant system with data isolation per company
    (EF Core query filters, JWT claims, RBAC with JSONB permissions)
  - Authored ADRs (Architecture Decision Records) to document
    technical choices and their rationale
  - Code reviews, team mentoring, coding standards definition


>> GPS Ingestion Service — Rust (High Performance)

  - Built from scratch an asynchronous TCP service in Rust (Tokio)
    capable of handling thousands of simultaneous connections
  - Implemented two proprietary GPS protocols:
      * HH Protocol: binary frame parsing (position, speed, heading, ignition)
      * AAP/ACI Protocol (V1, V2, V3): advanced MEMS data
        (accelerometer), FMS data (fuel, RPM, temperature, odometer)
  - Real-time driving event detection:
    harsh braking, acceleration, sharp turns, speeding
  - Redis integration (real-time position cache, pub/sub) and
    RabbitMQ (asynchronous event publishing)
  - Optimized persistence in PostgreSQL/PostGIS with batch inserts
    and time-series indexing
  - Docker-compatible graceful shutdown, structured logging (tracing),
    connection pooling, idiomatic error handling (Result, thiserror)


>> Backend API — .NET 8 (Clean Architecture / CQRS)

  - Developed 41 REST controllers covering: JWT authentication,
    vehicle management, geofencing, maintenance, reports, dashboard KPIs,
    system administration
  - Implemented SignalR hub for real-time GPS position broadcasting
    to clients (groups by company, vehicle, geofence)
  - Granular JSONB permission system with role management
    and subscription plans (vehicle, user, and module limits)
  - MediatR Pipeline Behaviors: validation (FluentValidation),
    structured logging (Serilog), transaction management
  - RabbitMQ integration: consuming GPS events for
    geofence evaluation, trip calculation, real-time alerts
  - Full vehicle lifecycle management: documents, costs
    (fuel, insurance, maintenance), accident claims, preventive
    maintenance (km/month intervals)
  - EF Core optimization: AsNoTracking, Select projections,
    compiled queries, pagination, batch operations


>> Frontend — Angular 17 (Standalone Components)

  - Developed 40+ standalone components:
      * Real-time Leaflet map with live vehicle tracking
      * GPS playback with controls (play/pause, speed, timeline slider)
      * Geofence drawing (polygons/circles) on map
      * Comprehensive reports (trips, fuel, speed, mileage)
      * Scheduled maintenance management
      * System administration panel (15 pages)
  - SignalR WebSocket integration for real-time updates
  - Guard system (AuthGuard, FeatureGuard, SystemAdminGuard)
    with permissions synchronized with backend
  - OSRM road snapping and Nominatim reverse geocoding


>> Database & Performance

  - Modeled 36 domain entities with multi-tenant hierarchy
    (Entity -> AuditableEntity -> TenantEntity)
  - PostgreSQL 16 + PostGIS: geospatial queries (ST_Contains,
    ST_Distance) for real-time geofencing
  - GPS position partitioning by date, composite indexes
    (device_id, recorded_at), BRIN indexes
  - JSONB for permissions, geofence coordinates, company settings
  - Redis: position cache with TTL, pub/sub for notifications
  - Report optimization: materialized views, window functions
    (LAG for fuel anomaly detection)


>> DevOps & Infrastructure

  - Full Dockerization of 8 services: .NET API, Rust service,
    PostgreSQL/PostGIS, Redis, RabbitMQ, Angular/Nginx, OSRM, Nominatim
  - Docker Compose with healthchecks, conditional depends_on,
    persistent volumes, multi-environment configuration (dev/prod)
  - Multi-stage Docker builds: Rust (cargo-chef, debian-slim ~50MB),
    .NET (sdk -> aspnet runtime ~200MB), Angular (node -> nginx:alpine)
  - CI/CD pipeline: lint, build, test, security scan, Docker build,
    automated deployment
  - Git Flow with conventional commits, mandatory code reviews,
    branching strategy (feature/develop/main)


>> Messaging & Integration

  - RabbitMQ: exchanges, durable queues, publisher confirms, ACK,
    dead letter queues, monitoring
  - Event-driven communication between services (fire-and-forget,
    eventual consistency)
  - Versioned JSON message format between Rust and .NET
  - Backpressure via bounded channels and prefetch_count
